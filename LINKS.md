- **Every link above now has a real book on a shelf.** Earlier, "recent
  developments" lived in a separate data field that nothing in the 3D scene
  actually rendered — orphaned data with no book. That's fixed: they're folded
  into each module's regular reading list (still visually recessed as REF-depth,
  slim spines, since they're "know about" items) so nothing in the library is
  invisible.
- A few URLs are intentionally repeated across shelves where a source is
  relevant to more than one module (e.g. the ACRA reporting page, the IEEFA
  JETP piece, the COP30 forests article, and IFC Performance Standards).
- Module C's shelf carries both the NZAOA 4th-edition protocol *and* a note that
  the 5th edition shipped Mar 2026 — check what changed before quoting mechanics
  at WCKD. Flagged in the Recency Checklist too.
- The 8 reference-cabinet tools (Rules & Rubric, 11-Day Plan, Party Mastery,
  Fact Bank, Options Bank, Vocabulary, Recency Checklist, Priority Reading List)
  hold team-generated content and outbound *search* links, not fixed sources,
  so they aren't listed here — see them live in the app.
- Source of truth is [`data/content.js`](data/content.js); regenerate this file
  from there if readings are added, removed, or re-sourced.
